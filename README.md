# Amura (Badoo) на Go1

Перенос бэкенда `~/PhpstormProjects/Badoo/backend` на фреймворк Go1. План и соответствия — `PLAN.md`,
выкладка на https://badoo.whales.team — `deploy/README.md`, стиль кода — `../Go1/docs/style.md`.

```sh
make setup      # зависимости + миграции (база из .env)
make run        # http://localhost:8080
make deploy     # на хостинг
```

Ядро подключено как `replace ../Go1/core` (go.mod): правки ядра видны сразу. Для боевой сборки по версии —
`go1 new --release` / `make core-update`.

## Это боевой бэкенд Amura (с 17.10.2026)

- Адрес: https://badoo.whales.team. Мобильное приложение — `../Badoo/mobile` (ходит сюда, `src/lib/config.ts`).
- Старый бэкенд `../Badoo/backend` (hermes1, badoo.surfer.team) заморожен — новое пишется только здесь.
- Выкладка одной командой из любого места: `badoo1deploy` (= `make test` + `make deploy`),
  `badoo1deploy --status`, `badoo1deploy --logs`. Алиас и все ключи — `../Badoo/COMMANDS.md`.


## Админка /control

https://badoo.whales.team/control — веб-админка в стиле StockGo1 (`modules/control`, лейаут CoreUI, статика в
`web/theme`, `web/plugins`). Мобильному приложению не нужна.

| раздел | что |
| --- | --- |
| Дашборд | люди (всего, новые, онлайн, DAU/WAU/MAU, Premium), пары, сообщения, голоса, встречи, очереди модерации, графики за 30 дней, города, новые анкеты и жалобы |
| Пользователи | список с фильтрами (поиск, статус, анкета, пол, возраст, город, цель, верификация, Premium, был в сети, фото, даты регистрации, жалобы, приложение, невидимки, сортировки) и карточка: анкета, фото, активность, пары и переписка, симпатии, гости, жалобы и блокировки, устройства, встречи, журнал. Действия: заблокировать/разблокировать, верификация, Premium, правка, удалить фото, выйти везде, удалить аккаунт (суперадмин) |
| Переписка | все диалоги, поиск по участнику и по тексту, поиск сообщений по всем диалогам, просмотр диалога, удаление сообщения |
| Встречи | события (предстоящие/прошедшие/тестовые), кто идёт и кто отметился, удаление |
| Модерация → Жалобы | новые / приняты меры / отклонены; заблокировать или отклонить сразу по всем жалобам на человека |
| Модерация → Верификация | очередь селфи рядом с фото анкеты: подтвердить / отклонить |
| Модерация → Фото | лента всех фото, удаление |
| Система → Журнал действий | кто из админов что сделал (`control_log`) |
| Система → Права | админы и их разделы, разделы меню и группы (как в StockGo1) |

Блокировка (`users.banned`): человек не входит ни на сайте, ни в приложении (сессии удаляются, Neuronet-вход
показывает причину), пропадает из колоды, «Рядом», симпатий, пар, гостей, чатов и встреч у всех.

Первый вход: войти на сайт своим аккаунтом, затем `make control-super WHO=<ваш email>` (локально —
`go run . control/super <email>`). Остальным админам разделы выдаются в «Права».

Подробно (первый запуск, блокировка, где код) — `ADMIN.md`; общий шаблон админок на Go1 — `../Go1/SUPERADMIN.md`.
