# Админка Amura — /control

https://badoo.whales.team/control — веб-админка (мобильному приложению не нужна). Сделана по общему шаблону
админок на Go1 — см. `../Go1/SUPERADMIN.md` (структура, как развернуть в новом проекте, как наращивать).

## Первый запуск / после обновления

```sh
badoo1deploy --skip-tests                       # выложить (миграции применяются при старте)
make control-super WHO=denis24art@gmail.com     # назначить суперадмина (из папки BadooGo1)
```

- Порядок важен: команда `control/super` есть только в новой сборке. «Неизвестная команда "control/super"» —
  значит, на сервере ещё старая версия, сначала `badoo1deploy`.
- «Пользователь не найден» — этот email ещё ни разу не входил: зайти на https://badoo.whales.team через Neuronet,
  потом повторить `make control-super`.
- Суперадмину открываются все разделы, его права из админки не меняются, новые разделы появляются у него сами.
- Остальных админов назначают в «Система → Права»: найти пользователя → включить нужные разделы.
- Локально: `go run . control/super <email или id>`.
- Строку «unnecessarily importing … go-sqlite3/embed» в выводе можно не замечать — безвредное предупреждение библиотеки.

## Разделы

| раздел | адрес | что |
| --- | --- | --- |
| Дашборд | `/control` | люди (всего, новые, онлайн, DAU/WAU/MAU, Premium), пары, сообщения, голоса, встречи, очереди модерации, графики за 30 дней, города, новые анкеты и жалобы |
| Пользователи | `/control/users` | ~20 фильтров (в адресе страницы — ссылкой можно поделиться); карточка `/control/users/view?uid=` с вкладками: анкета и фото, активность, пары и переписка, симпатии, гости, жалобы и блокировки, устройства, встречи, журнал |
| Переписка | `/control/chats` | все диалоги, поиск по участнику и тексту, поиск сообщений по всем диалогам, просмотр диалога, удаление сообщения |
| Встречи | `/control/meetups` | предстоящие / прошедшие / тестовые, кто идёт и отметился, удаление |
| Модерация → Жалобы | `/control/reports` | новые / приняты меры / отклонены; заблокировать или отклонить сразу все новые жалобы на человека |
| Модерация → Верификация | `/control/verification` | селфи рядом с фото анкеты: подтвердить / отклонить |
| Модерация → Фото | `/control/photos` | лента всех фото, удаление |
| Система → Журнал действий | `/control/log` | кто из админов что сделал (`control_log`) |
| Система → Права | `/control/permissions` | админы и их разделы, разделы меню и группы |

В меню — счётчики новых жалоб и селфи на проверке.

## Действия с пользователем

Заблокировать / разблокировать (с причиной), верификация, Premium (+N дней / снять), правка анкеты (имя, о себе,
город, выключить невидимку), удалить фото / сделать главным, «выйти везде», удалить аккаунт (только суперадмин).
Всё пишется в журнал действий.

**Блокировка** (`users.banned`, `components/users/moderation.go`):
- выход на всех устройствах: Bearer-токены приложения удалены, `auth_key` сменён (cookie сайта не работает);
- войти заново нельзя: `neuronet.syncUser` отвечает «Аккаунт заблокирован. Причина: …»;
- `auth.Finder` не находит заблокированного — сайт считает гостем, API отвечает 401;
- анкета пропадает у всех: колода, «Рядом», симпатии, пары, гости, чаты (`users.NotBlocked`), встречи (`goingNotBlocked`);
- push-токены удалены, непрочитанные от него у собеседников обнулены, новые жалобы на него закрыты.

Защита: нельзя заблокировать себя и суперадмина; админа блокирует только суперадмин.
